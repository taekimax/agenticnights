# agenticnights

작업 중인 Mac을 깨어 있게 유지하면서, 정해진 간격마다 화면을 검게 덮는
작은 macOS 메뉴 막대 앱입니다. 외부 라이브러리나 전체 Xcode 없이 빌드합니다.

현재 버전은 **1.1.2**이며, macOS 13 이상에서 실행됩니다. 화면 보호와 잠자기
방지를 각각 켜고 끌 수 있고, 시간대 지정과 잠자기 방지 자동 종료 타이머를
지원합니다. 검은 화면은 키 입력이나 클릭으로 해제합니다.

### 직접 실행하거나 에이전트가 참고할 명령

요구 사항: **macOS 13 이상**, Git, Xcode Command Line Tools의 Swift, python3.
전체 Xcode 앱이나 외부 패키지 설치는 필요하지 않습니다. Apple Silicon 또는 Intel
Mac에서 해당 아키텍처로 빌드합니다. 다른 아키텍처에서는 그 Mac에서 다시 빌드하세요.

새 체크아웃을 만드는 경우:

```sh
mkdir -p "$HOME/dev"
git clone https://github.com/taekimax/agenticnights.git "$HOME/dev/agenticnights"
cd "$HOME/dev/agenticnights"
./Scripts/test.sh
./Scripts/build.sh
./Scripts/install.sh
open /Applications/agenticnights.app
```

기존 체크아웃에는 `git clone`을 반복하지 말고 Git 상태와 로컬 변경을 먼저
확인하세요. 공개 소스 읽기는 위 HTTPS 주소를 사용할 수 있으며, 인증이 필요한
개발 작업은 기존 SSH 설정을 사용하세요.

- 빌드 결과: `.build/agenticnights.app`
- 설치 위치: `/Applications/agenticnights.app`
- 기존 앱 복구본: `~/.Trash/agenticnights-<타임스탬프>.app`
- 로컬 ad-hoc 서명을 사용합니다. 앱은 네트워크·접근성·화면 녹화 권한을 요청하지 않습니다.
- 처음 실행하면 설정 창이 열립니다. 이후에는 메뉴 막대에서 설정을 열거나
  Applications의 앱을 다시 열어 설정할 수 있습니다.
- 설치 스크립트는 기존 동일 앱을 정상 종료하고 복구본을 보관한 뒤 복사합니다.
  설치 전후 deep/strict 서명과 전체 파일 일치를 확인합니다.
- 빌드 컴파일 스레드는 2개로 제한합니다.
- `LICENSE`와 `THIRD_PARTY_NOTICES.md`는 앱의 `Contents/Resources/`에도 포함됩니다.

## 사용

메뉴 막대에는 **달 아이콘 하나**만 표시합니다. 설정의 **달 아이콘 클릭**에서
실행할 기능을 선택합니다.

| 설정 | 달 아이콘 클릭 |
| --- | --- |
| 화면 보호 | 자동 화면 보호만 켜기/끄기 |
| 잠자기 방지 | 잠자기 방지만 켜기/끄기 |
| 화면 보호 + 잠자기 방지 (기본값) | 두 기능을 함께 켜기/끄기 |

선택한 기능 중 하나라도 켜져 있으면 클릭으로 모두 끄고, 모두 꺼져 있으면
클릭으로 켭니다. 선택하지 않은 기능은 유지됩니다. 켤 때에는 각 기능에 저장된
타이머와 작동 시간대가 적용되므로 시간대 밖에서는 시작 시각까지 기다립니다.
클릭할 작업을 선택하는 것만으로 실행 상태나 진행 중인 타이머가 바뀌지는 않습니다.

선택한 기능이 켜져 있으면 채워진 달, 꺼져 있으면 흐린 윤곽 달로 표시합니다.
포인터를 올리면 두 기능의 현재 상태와 클릭 시 실행할 작업을 볼 수 있습니다.
**우클릭, Control-클릭 또는 Option-클릭**으로 설정과 수동 가리기 메뉴를 엽니다.

- **화면 보호**: 분 단위 가림 간격과 매일의 작동 시간대를 정합니다.
  한 주기가 지나면 처음 가리며 수동 가림은 다음 주기를 다시 시작합니다.
  초기 기본값은 10분, 시간대 제한 없음, 자동 화면 보호 켜짐입니다.
- **잠자기 방지**: 화면 보호와 별도로 Mac과 디스플레이의 자동 잠자기를 막습니다.
  켜기/끄기, 자동 종료 타이머(1–1440분), 매일의 작동 시간대를 따로 정합니다.
  초기 기본값은 켜짐, 타이머와 시간대 제한 없음입니다.
- 잠자기 방지 타이머는 시간대 안에서 **실제 작동이 시작될 때** 시작합니다.
  타이머가 끝나면 잠자기 방지 스위치도 꺼집니다. 끄고 다시 켜면 새 타이머가
  시작됩니다. 앱 재실행·잠자기 후 복귀·화면 보호 설정 변경은 종료 시각을 연장하지
  않습니다. 시작된 타이머는 시간대 밖이나 앱을 종료한 동안에도 시간이 흐릅니다.
  타이머 분수나 타이머 사용 여부를 바꾸면 새 설정으로 다시 시작합니다.
- 시간대는 시작 시각을 포함하고 종료 시각에 멈춥니다. `22:00–07:00`처럼
  자정을 넘는 시간대를 지원하며, 시작과 종료가 같으면 하루 종일 작동합니다.
  타이머를 사용하지 않으면 지정 시간대에 매일 반복합니다.
- **검은 화면에서 메뉴 막대 숨기기**는 초기 기본값으로 켜져 있습니다.
  체크를 해제하면 가림 중에도 메뉴 막대를 사용할 수 있습니다.
  가림이 끝나면 이전 메뉴 막대·Dock 표시 상태로 복원합니다.
- **지금 가리기**, **가림 해제**, **⌃⌥⌘B**로 수동 제어합니다.
  검은 화면에서 **키 입력**(문자, Space, Enter, 방향키, Esc 등) 또는 클릭으로
  해제할 수 있습니다. 해제에 사용한 키는 이전 앱에 전달하지 않습니다.
  수동 가리기는 잠자기 방지의 켜짐/꺼짐을 바꾸지 않습니다.
- 검은 창은 일반 창 높이(`NSWindow.Level.normal`)입니다. 다른 앱으로
  전환하면 가림을 해제합니다. 설정을 열어 둔 동안은 자동 가림을 건너뜁니다.
- 설정 창을 닫거나 취소하면 저장값은 유지됩니다. 열려 있는 동안 타이머가
  끝나거나 메뉴 막대에서 전환하면 수정하지 않은 스위치에 현재 상태가 반영됩니다.
  설정 창을 다시 열려면 Applications에서 앱을 열어도 됩니다.
- 앱 업데이트 시 저장된 설정을 유지합니다. 이전 설정 형식도 읽을 수 있으며,
  화면 보호와 잠자기 방지는 각각 독립적으로 작동합니다.
- 앱을 종료하면 이 앱이 시작한 `caffeinate`만 종료합니다.
  시스템의 영구 잠자기 설정이나 다른 앱의 잠자기 방지를 변경하지 않습니다.

가림은 잠금 화면이나 별도 전체화면 Space가 아닙니다. 검은 화면이 표시될 때
앱이 활성화되며, 다른 앱을 활성화하거나 가림을 해제하면 계속 작업할 수 있습니다.
잠자기 방지는 macOS의 수동 잠자기·덮개 닫기 정책을 우회하지 않습니다.

## 개발과 상태 확인

- 설정: `com.tk.agenticnights` UserDefaults의 `settings` JSON 데이터.
- 현재 상태: `~/Library/Application Support/agenticnights/status.json`.
  앱 경로, 두 기능의 실행 상태/시간대, 다음 가림 시각, 타이머 종료 시각,
  가림 창 크기와 잠자기 방지 프로세스를 기록하며
  화면 내용이나 키 입력은 저장하지 않습니다. 상태 파일은 앱이 쓴 마지막
  스냅샷이므로 실제 실행 여부는 PID와 실행 경로를 함께 확인합니다.

| 파일 | 역할 |
| --- | --- |
| `Sources/Schedule.swift` | 설정 모델, 일정 계산과 자동 종료 타이머 |
| `Sources/CoverController.swift` | 디스플레이별 가림 창과 입력에 따른 해제 |
| `Sources/SleepPrevention.swift` | 앱 수명에 연결된 잠자기 방지 프로세스 |
| `Sources/SettingsWindow.swift` | 설정 편집과 저장·취소 |
| `Sources/GlobalShortcut.swift` | 전역 단축키 등록과 해제 |
| `Sources/main.swift` | 메뉴 막대, 설정 저장과 앱 동작 연결 |

빌드 결과와 로컬 검증 자료는 `.build/` 아래에 생성되며 Git에서 제외됩니다.
소스를 배포할 때는 `LICENSE`와 `THIRD_PARTY_NOTICES.md`를 함께 포함하세요.

## 테스트

저장소 루트에서 다음 명령을 실행합니다.

```sh
./Scripts/test.sh
./Scripts/build.sh
```

현재 자동화 테스트는 **25개**입니다. 일정의 시작·종료 경계, 자정을 넘는 시간대,
서머타임, 타이머 만료와 저장, 설정 호환성, 두 기능의 독립적인 전환과
아이콘 동작 선택을 확인합니다. 성공하면 `PASS: 25 schedule tests`를 출력합니다.

빌드는 현재 Mac 아키텍처용 앱을 생성하고 로컬 서명을 검사합니다.
테스트와 빌드 명령은 앱을 설치하거나 실행하지 않습니다. 실제 메뉴 막대 조작,
키 입력에 따른 가림 해제, 여러 디스플레이에서의 표시와 macOS 잠금·잠자기
동작은 설치 후 별도로 확인해야 합니다.
